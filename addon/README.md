# Govee to MQTT bridge: Home Assistant Add-On

This addon provides a bridge between [Govee](https://govee.com) lights and Home Assistant,
via the [Home Assistant MQTT Integration](https://www.home-assistant.io/integrations/mqtt/).

Add `https://github.com/h44z/govee2mqtt` to the Home Assistant Add-on Store
repositories, then install **Govee to MQTT Bridge**.

Installation compiles a pinned revision of this fork for AMD64 or ARM64.
The first build needs internet access and can take several minutes, especially
on a Raspberry Pi. No prebuilt container from the upstream project is used.

See the **Documentation** tab for setup instructions.
